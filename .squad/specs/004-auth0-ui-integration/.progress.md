## Key Decisions Made During Implementation

1. **ROPG rejected**: Playwright auth uses UI login + storage-state reuse instead of Resource Owner Password Grant (would require manual Auth0 dashboard step, violating FR-019)
2. **`app_metadata` for RBAC**: Auth0 Free tier does not include native RBAC; custom claims via Auth0 Action used instead
3. **`proxy.ts` over `middleware.ts`**: Next.js 16 convention; handles rolling sessions with broad matcher
4. **Single public entry point**: `useAuth()` hook — components never import Auth0 SDK directly
5. **Role claim namespace**: `https://yt-summarizer.com/role` to avoid JWT claim collisions
